# Focus Studio

Автономный статический сайт для GitHub Pages. Сборка и сервер не нужны: GitHub Pages должен видеть `index.html` в корне выбранной ветки.

В интерфейсе оставлены два визуальных режима — солнце и луна — и отдельный простой режим `Timer`. Небесное тело меняет положение и состояние постепенно по мере обратного отсчёта; декоративных стикеров и лишних режимов нет.

Функции: крупный постоянно видимый таймер, полноэкранный режим, ручной выбор длительности от 1 до 180 минут, пауза, +5 минут, сброс к выбранной длительности, включаемый/выключаемый сигнал, светлая/тёмная тема и сохранение состояния при уходе Safari в фон.
